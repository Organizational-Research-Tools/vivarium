# Materials qualification

Nine client projects in three related groups. Each project is qualified on its heat,
strength and water tests; `lab_info` states what qualifies a project and the thresholds. It
also says which parts of a recipe are known to interact and which test each interaction
affects, not what the interaction is.

Every complete qualification needs measurements from all three instruments. You operate
one. The directory in `lab_info` names who operates the others.
