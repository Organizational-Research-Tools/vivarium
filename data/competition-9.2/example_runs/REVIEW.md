# Review of the example runs before release

Reviewed on October 29, 2026, before publication, with the project's release tooling
(`scripts/release_example_review.py`). The detailed results are in `REVIEW.json`.

## What was checked

1. **Credentials.** The release's credential scanner (`scripts/release_secret_scan.py --tree`), over every file,
   compressed files read decompressed: matches: 0.
2. **Provider content.** No run has a `raw/` folder (the providers' raw responses), and no `reasoning.step` event
   keeps its `thinking` field (the reasoning text the providers returned). Every other line of each event record is
   byte-identical to the original archive.
3. **Personal data.** A screen of every text file for e-mail addresses, phone numbers, IP addresses, home-directory
   paths, web addresses, and the local user's and folders' names. The two absolute file paths each `manifest.json`
   held (the preset and the task manifest, which named the local user and folders) were rewritten to
   repository-relative paths before this review.
4. **Content from outside the synthetic task.** A screen for the names of real organizations and services (model
   providers, technology companies, social media).
5. **Content the providers' usage policies bar.** A keyword screen by category: sexual content, slurs and hate,
   weapons and violence, self-harm, minors.

Every screen found nothing in every run. Each run folder carries `MODELS.md`, which states that the content is
AI-generated, names the provider and model behind every role (from the manifest's `role_model_refs`), and gives the
notice against training; the bundle's `README.md` repeats both.

**What this review is not.** The screens are automated, and any hit would have been inspected by hand; none
occurred. No person read every step of the ten runs (tens of thousands of messages and tool calls). The runs come
from a sealed, synthetic task without network access, which bounds what they can contain, but a line-by-line human
reading has not been done.
