# Process coding (not released)

The process coding of the main study (preregistration §6; `docs/experiments/pc1_process_coding.md`,
`docs/experiments/pc1_codebook.md`, `docs/experiments/pc1_light_coding_brief.md`): a first coder over the runs the
coding screen selected and a second coder on a 20% sample. Its codes enter `../runs.csv` as the coded outcomes
(`labs_deciding`, `objecting_labs_coded`, `objection_time`). The coding sheets themselves are not released: each
code rests on a quotation from the run, which is model output.
