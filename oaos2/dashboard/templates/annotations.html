Mark up runs while you read them. Your marks are saved in a separate file next to each run's records. They are separate research data, not a cache that can be reconstructed from the trace. The dashboard appends labels and defaults their coder field to “human”; that field does not verify who supplied a judgment. Preserve original coding and document corrections under the study's coding rules.

Lenses. A lens is a category YOU define for marking events while reading — like a highlighter color with a meaning (e.g. 'framing move', 'attention shift'). Once defined, every event page gets a 'Code it' button for it.

Arity. How many events one mark spans: unary = one event, relational = two-plus events that stand in a relation (e.g. 'this volley echoes that one'), group = any set of events.
