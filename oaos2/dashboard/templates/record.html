Record is where you check a run before relying on it. It interprets nothing; it answers three questions.

Can I trust the record? The first card: whether the archive checks passed, how the run ended, what the automatic diagnostics found, and any trouble events. Passing shows the record is internally consistent, not that a research claim is true.

What exactly ran? Identity and pins: the model, task materials, organization, code version, and price table the run saved. Hashes detect change; they do not reconstruct a file that is gone.

Where is the evidence? The links under the tabs open every event, the saved files, the full audit, and the flow at full depth. Events by class and the raw configuration are further down.

Two kinds of caution. "Recorded in this run" lists conditions that change how the result may be read. "About the archive" lists facts about the repository then or now, such as materials that have changed since.
