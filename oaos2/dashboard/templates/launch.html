Offline (free)

Offline execution checks wiring with simulated behavior and task evaluators. It does not validate live model capacity or produce confirmatory evidence. Results are saved under this dashboard's runs root.

Live (PAID)

Requires the typed phrase, an explicit per-run cap, the local Docker daemon, and provider credentials. Keep the machine awake. Confirmatory runs additionally require a FINAL preregistration and matching calibration evidence for the actual settings; an existing preregistration file is insufficient. Live runs are saved under the repository's runs/.

Historical clock-capacity calibration · clock_density

This specialized runner was used to calibrate clock and capacity settings for the budget-execution task. It remains available for that machinery; it is not the current study. Consult Study records for the active design and its requirements before reusing it.

PYTHONPATH="$PWD" python scripts/run_clock_density_sweep.py --offline
PYTHONPATH="$PWD" python scripts/run_clock_density_sweep.py --live --arms solo,vertical,lateral --cap-usd <authorized-cap>

The second command is paid and still requires explicit spend authorization. The dashboard does not invent clock horizons, wave spreads, schedule assets, or authorization on the researcher's behalf.
